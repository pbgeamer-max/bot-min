# 🤖 Minecraft AFK & Pathfinding Bot (DonutSMP & Premium Compatible)

مشروع بوت Minecraft متطور مبني بلغة **Node.js** ومكتبات **Mineflayer** و **mineflayer-pathfinder**، مزود بـ **لوحة تحكم ويب تفاعلية**. 
يدعم السيرفرات الرسمية والأصلية المشهورة مثل **DonutSMP** (`donutsmp.net` / `EU.donutsmp.net`) بحسابات مايكروسوفت الرسمية، كما يدعم سيرفرات Aternos المكركة (Cracked).

---

## ✨ المميزات الرئيسية

1. **دعم السيرفرات الأصلية (DonutSMP / Hypixel / وغيرها)**:
   - دعم التوثيق الرسمي لحسابات مايكروسوفت (`auth: 'microsoft'`).
   - حفظ التوكن محلياً في `auth-cache/` بحيث لا تحتاج لتسجيل الدخول سوى مرة واحدة فقط.
   - عرض رابط وكود التفعيل تلقائياً في واجهة الويب مع زر نسخ بضغطة زر.

2. **تحديد مكان الوقوف بدقة (Exact Coordinates X, Y, Z)**:
   - إمكانية إدخال إحداثيات الهدف بدقة (X, Y, Z).
   - توجيه البوت باستخدام نظام الملاحة الذكي والواقعي (**Pathfinder**) للسير نحو الهدف وتجنب العوائق بدون كسر البلوكات.
   - **تثبيت البوت (Lock Position)**: إذا قام وحش أو لاعب بدفع البوت بعيداً عن موقعه بأكثر من بلوكين، يعود البوت فوراً وبشكل تلقائي إلى مكان الوقوف المحدد!
   - زر "تحديد موقعي الحالي كهدف" لالتقاط إحداثيات البوت الحية وحفظها بضغطة واحدة.

3. **الانتقال التلقائي وعالم الـ SMP (Auto-Commands)**:
   - دعم إرسال أوامر تلقائية عند الدخول (مثل `/smp` أو `/join` أو `/queue`) بعد مهلة انتظار محددة بالثواني للدخول إلى ريلم السيرفر.

4. **لوحة تحكم ويب تفاعلية متكاملة (Web Dashboard)**:
   - متابعة الإحداثيات اللحظية للبوت (X, Y, Z) وحالته (واقف / يسير).
   - موجه أوامر وشات مباشر لإرسال أوامر للسيرفر (مثل `/smp`, `/home`, `/tpa`) دون الحاجة لفتح اللعبة.
   - أزرار إعدادات سريعة (Presets) لسيرفرات DonutSMP (US), DonutSMP (EU), و Aternos.

5. **نظام Anti-AFK ذكي وآمن من الطرد**:
   - حركات طبيعية (التفات خفيف بالرأس، انحناء لطيف Sneak، تحريك اليد) بدون مغادرة البلوك أو التسبب بطرد من برامج Anti-Cheat مثل GrimAC أو Vulcan.

## 🎮 كيفية تشغيل البوت مع سيرفرات DonutSMP (`donutsmp.net` / `EU.donutsmp.net`)

1. شغّل السكريبت محلياً عبر:
   ```bash
   npm start
   ```
2. افتح لوحة التحكم في المتصفح: `http://localhost:3000`
3. أدخل كلمة المرور (الافتراضية: `f1bot123`).
4. اضغط على زر الإعداد السريع: **DonutSMP (US)** أو **DonutSMP (EU)**.
5. تأكد من تحديد نوع المصادقة: **حساب أصلي رسمي (Microsoft)**.
6. اكتب اسم البوت أو إيميل الحساب واضغط **بدء الاتصال (Connect)**.
7. سيظهر لك إشعار وبانر تسجيل الدخول بحساب مايكروسوفت مع رابط وكود مثل: `ABCD-EFGH`.
8. افتح الرابط وأدخل الكود لربط الحساب (مرة واحدة فقط).
9. سينضم البوت تلقائياً إلى السيرفر ويرسل أمر `/smp` بعد 7 ثوانٍ.
10. يمكنك الآن إدخال إحداثيات المكان (X, Y, Z) والضغط على **انتقال إلى الإحداثيات الآن** أو تفعيل خيار **تثبيت البوت** ليبقى في مكانه دائماً!
