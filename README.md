# 🤖 Minecraft AFK Bot (Railway & Aternos Compatible)

مشروع بوت Minecraft AFK مبني بلغة **Node.js** ومكتبة **Mineflayer** ومصمم خصيصاً للعمل على منصة **Railway** بشكل مجاني ودائم (24/7) للبقاء متصلاً بسيرفرات Minecraft (مثل Aternos) ومنع إغلاق السيرفر عند خروج اللاعبين.

---

## ✨ المميزات الرئيسية

1. **آلية Anti-AFK حركية عشوائية**: يقوم البوت بتنفيذ حركات عشوائية (القفز، الالتفاف، الانحناء، تحريك اليد) كل 30 ثانية لتجنب طرده بواسطة نظام Anti-AFK المدمج في السيرفر.
2. **إعادة اتصال تلقائية (Auto-Reconnect)**: يعيد البوت الاتصال بالسيرفر تلقائياً كل 15 ثانية في حال تم طرده أو عند إعادة تشغيل السيرفر.
3. **معالجة شاملة للأخطاء (Crash Prevention)**: حماية السكريبت من الانهيار عند حدوث أخطاء الشبكة أو فقدان الاتصال.
4. **خادم HTTP للفحص الصحي (Health Checks)**: خادم HTTP مدمج بسيط لإجابة طلبات الصحة الخاصة بـ Railway لضمان عدم إيقاف الحاوية.
5. **دعم كامل لـ Aternos**: يعمل بسهولة مع سيرفرات Aternos المكركة (Cracked).

---

## 🛠️ متغيرات البيئة (Environment Variables)

تحتاج إلى ضبط المتغيرات التالية في لوحة تحكم **Railway**:

| المتغير | الوصف | مثال | إجباري؟ |
| :--- | :--- | :--- | :--- |
| `HOST` | عنوان IP أو رابط سيرفر Minecraft | `myserver.aternos.me` | **نعم** |
| `MC_PORT` | بورت السيرفر (افتراضياً 25565 إذا لم يُحدد) | `12345` | لا (حسب سيرفرك) |
| `USERNAME` | اسم البوت داخل اللعبة | `AFK_Bot_247` | **نعم** |
| `VERSION` | إصدار اللعبة (يتم التعرف عليه تلقائياً إن ترك فارغاً) | `1.20.1` | لا |
| `AUTH` | نوع المصادقة (`offline` لـ Aternos المكرك، أو `microsoft`) | `offline` | لا (الافتراضي `offline`) |

> 💡 **ملاحظة للبورت**: يمكنك كتابة العنوان مع البورت مباشرة في متغير `HOST` مثل `myserver.aternos.me:12345` وسيقوم البوت بفصله تلقائياً.

## 🚀 كيفية النشر على منصة Railway (Step-by-Step)

1. **رفع المشروع إلى GitHub**:
   - قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub.
   - قم برفع جميع ملفات هذا المشروع (`index.js`, `package.json`, `.gitignore`, `README.md`).

2. **الربط مع Railway**:
   - توجه إلى لوحة تحكم [Railway.app](https://railway.app/).
   - اضغط على **New Project** ثم اختر **Deploy from GitHub repo**.
   - اختر مستودع البوت الذي قمت برفعه.

3. **إضافة متغيرات البيئة (Variables)**:
   - بعد اختيار المستودع، انتقل إلى تبويب **Variables** في مشروعك على Railway.
   - اضغط على **Add Variable** وأضف المتغيرات التالية:
     - `HOST`: رابط سيرفرك (مثال: `yourname.aternos.me`)
     - `MC_PORT`: بورت سيرفرك في Aternos (مثال: `54321`)
     - `USERNAME`: اسم البوت (مثال: `AFK_Bot`)
   - قم بحفظ التغييرات وسيتم إعادة نشر المشروع تلقائياً.

4. **التحقق من السجلات (Logs)**:
   - انتقل إلى تبويب **Deployments** ثم افتح **View Logs**.
   - ستلاحظ انطلاق خادم الـ HTTP ودخول البوت إلى سيرفرك بنجاح!

---

## ⚠️ نصائح مهمة لسيرفرات Aternos

1. **تفعيل وضع Cracked (المكرك)**:
   - افتح لوحة تحكم Aternos -> انتقل إلى **Options (الخيارات)** -> قم بتفعيل خيار **Cracked (مكرك)** ليتمكن البوت من الدخول بنوع مصادقة `offline`.
2. **تشغيل السيرفر لأول مرة**:
   - تأكد من تشغيل سيرفر Aternos يدوياً لأول مرة، وبمجرد دخول البوت وسيرفر Aternos يعمل، لن يغلق السيرفر طالما البوت متصل بداخله.
