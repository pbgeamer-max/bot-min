# 🤖 منصة تأجير بوتات ماينكرافت (AFK Bot SaaS Platform)

منصة سحابية متطورة لتأجير بوتات ماينكرافت التلقائية (AFK Bots) لسيرفرات **DonutSMP** (`donutsmp.net` / `EU.donutsmp.net`) بنظام الاشتراكات الأسبوعية (مثل 40,000 دينار عراقي/أسبوع)، مع لوحة تحكم مستقلة لكل مشترك، وفصل آلي للخدمة فور انتهاء مدة الاشتراك بدعم كامل لقاعدة بيانات **Firebase**.

---

## ✨ المميزات الرئيسية للمنصة

1. **نظام اشتراكات أسبوعية مؤقتة (7 أيام)**:
   - يحصل كل زبون على حسابه الخاص لمراقبة والتحكم في بوته فقط.
   - مؤقت عد تنازلي حي يوضح الأيام والساعات المتبقية من الاشتراك.
   - **قفل آلي فوري (Automatic Expiry)**: بمجرد انتهاء الـ 7 أيام، ينفصل البوت فوراً من سيرفر DonutSMP، وتنغلق لوحة التحكم بشاشة قفل تطالب بالتجديد أو إدخال كود جديد.

2. **دعم قاعدة بيانات Firebase Firestore مع خيار محلي تلقائي**:
   - يدعم الاتصال السحابي المباشر بـ **Firebase** لتخزين المشتركين والاشتراكات بشكل دائم دون فقدان البيانات عند إعادة تشغيل السيرفرات.
   - إذا لم تُضف مفاتيح فايربيس بعد، يعمل النظام تلقائياً بوضع التخزين المحلي الآمن (`data/local-db.json`) دون أي توقف أو انهيار.

3. **لوحة تحكم المسؤول والأرباح (Admin Super-Panel)**:
   - حساب الأدمن الرئيسي (`admin` / كلمة مرورك `f1bot123`).
   - متابعة إجمالي الأرباح المستلمة بالدينار العراقي (مثال: 40,000 د.ع لكل مشترك).
   - زر **توليد أكواد اشتراك أسبوعية** (`F1-7D-XXXX-YYYY`) بضغطة واحدة لترسلها للزبون عبر واتساب أو تليجرام بعد استلام التحويل (زين كاش).
   - إمكانية تمديد أي اشتراك (+7 أيام) بنقرة زر واحدة.

4. **تحديد مكان الوقوف والملاحة الذكية (Pathfinder)**:
   - يحدد الزبون إحداثيات مزرعة الـ AFK بدقة (X, Y, Z).
   - يسير البوت نحو الموقع بذكاء وبطريقة طبيعية دون كسر البلوكات.
   - **تثبيت البوت (Lock Position)**: إذا دفعه وحش أو لاعب بعيداً، يعود تلقائياً لمكانه.

5. **دعم سيرفرات DonutSMP وحسابات مايكروسوفت**:
   - دعم التوثيق الرسمي لمايكروسوفت (`auth: 'microsoft'`) مع حفظ جلسة الدخول في مجلد معزول لكل زبون (`auth-cache/<userId>/`).
   - أمر دخول الـ SMP التلقائي (`/smp`) مع شات مباشر لإرسال أي أمر في السيرفر.

## 🛠️ كيفية تفعيل قاعدة بيانات Firebase (خطوة اختيارية وسهلة جداً)

النظام يعمل تلقائياً حالياً، ولكن لربطه بـ Firebase الرسمي:
1. افتح [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً جديداً.
2. أنشئ قاعدة بيانات **Firestore Database** (في وضع Test mode أو Production).
3. انتقل إلى **Project Settings (إعدادات المشروع)** > **Service accounts**.
4. اضغط على **Generate new private key** (توليد مفتاح خاص جديد) وسيتم تحميل ملف باسم `serviceAccountKey.json`.
5. ضع الملف في مجلد المشروع الرئيسي بجوار `index.js`.
6. سيتعرف السيرفر عليه فوراً ويظهر لك في اللوحة: `Firebase Firestore 🟢`.

## 🎮 كيفية تشغيل المنصة

1. شغّل المنصة محلياً:
   ```bash
   npm start
   ```
2. افتح المتصفح على: `http://localhost:3000`
3. **للدخول كمسؤول (Admin)**:
   - اسم المستخدم: `admin`
   - كلمة المرور: `f1bot123` (أو القيمة المحددة في `WEB_PASSWORD`)
   - اضغط على زر **لوحة الإدارة والأرباح** بالأعلى لتوليد أكواد أو تمديد الاشتراكات ومتابعة الأرباح.
4. **للمشترك (الزبون)**:
   - يفتح الموقع ويضغط على تبويب **حساب جديد / كود اشتراك**.
   - يدخل اسم مستخدم وكلمة مرور وكود الاشتراك الذي اشتراه منك.
   - تبدأ الـ 7 أيام بالعد التنازلي ويتحكم في بوته بالكامل!
